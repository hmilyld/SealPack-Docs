## Click semantics

| Area | Click behaviour |
| --- | --- |
| Whole row (name / icon / size / status) | Toggle selection; locked rows only take focus |
| Expand arrow | Expand / collapse only, **never changes selection** |
| Checkbox | Toggle selection (a folder covers its subtree), **never collapses** |

Clicking a folder row toggles its whole subtree using the tri-state aggregate. Use the arrow to expand it,
so "I meant to expand but selected everything" no longer happens.

<Callout tone="note" label="Keyboard">

The tree uses a roving tabindex: one focus position for the whole tree. <Kbd>↑</Kbd> <Kbd>↓</Kbd> move,
<Kbd>→</Kbd> <Kbd>←</Kbd> expand / collapse or enter / leave a folder, and <Kbd>Space</Kbd> or
<Kbd>Enter</Kbd> toggles selection. <Kbd>Ctrl</Kbd> + <Kbd>A</Kbd> selects all visible files.

</Callout>

## Three ways to find a file

1. **You know roughly where it is** → expand folders. The tree is unfiltered by default.
2. **You know the type** → use the extension chips, for example only `.dll`.
3. **You know the name** → the search box. Matches are highlighted, ancestors expand, and manual collapse
   state is restored when the search is cleared.

On the Package step, **Select all / Exclude all** walk the entire tree, including collapsed folders and
files hidden by filters. Auto-excluded items, rule matches and the main executable stay unchanged. This
is why "Exclude all" usually leaves a count of 1: the main executable is always packed.

## View state is not selection state

- **Selection changed** writes back to the project and triggers the debounced save.
- **View changed** (collapse, search, extension filter) only changes what is visible and is not saved.

The footer's "showing N" must follow the view. Directory scanning and ignore refresh each have their own
monotonic epoch; a stale response after switching projects is discarded. Keep the two counters separate.

<Callout tone="pitfall" label="Files deleted outside SealPack">

The tree cannot know when files are deleted in Explorer. Right-click the project row and choose
**Reload project**; it re-reads the project JSON and rescans the main program folder.

</Callout>
