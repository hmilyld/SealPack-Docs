## Shortcuts

| Shortcut | Action |
| --- | --- |
| <Kbd>Ctrl</Kbd> + <Kbd>,</Kbd> | Open settings |
| <Kbd>Ctrl</Kbd> + <Kbd>W</Kbd> | Close the window |
| <Kbd>Alt</Kbd> + <Kbd>←</Kbd> / <Kbd>→</Kbd> | Previous / next wizard step |
| <Kbd>Esc</Kbd> | Close the context menu or dialog |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd> <Kbd>Home</Kbd> <Kbd>End</Kbd> | Move focus in the tree and in menus |
| <Kbd>→</Kbd> <Kbd>←</Kbd> | Expand / collapse, step into / out of a folder |
| <Kbd>Space</Kbd> / <Kbd>Enter</Kbd> | Toggle the tree checkbox |
| <Kbd>Ctrl</Kbd> + <Kbd>A</Kbd> | Select all visible files |

Inside a dialog, <Kbd>Tab</Kbd> cycles within the panel and <Kbd>Enter</Kbd> triggers the primary action.
The primary action is on the right and Cancel on the left (Fluent convention). When the settings dialog
opens, focus starts on the dialog container, so the first tab does not get an initial focus ring.

<Callout tone="pitfall" label="Do not swallow Esc">

The global table runs in the **capture** phase on `window` and only calls `preventDefault` — it never
calls `stopPropagation`. Overlays (dialogs, the context menu) handle <Kbd>Esc</Kbd> themselves; if the
global table swallows it, the dialog cannot be closed.

</Callout>

## Context menu

| Where | Items |
| --- | --- |
| Project row | Open executable folder / open output folder / reload project / copy project name / rename… / delete project… |
| File tree | Copy path / reveal in Explorer |
| Run log | Copy all output / save log / clear log |
| Inputs and script area | Native edit menu (cut / copy / paste / spell check) |

**Reload project** first saves any pending edits, then re-reads the project JSON from disk and rescans the
main program folder. Use it after deleting files outside SealPack.

**Rename…** opens a dialog prefilled with the main executable's `ProductName` (falling back to the file
name). The project name is used for the installer name, default install directory, and output file name;
the executable and old artifacts are not renamed.

**Delete project…** removes only the project configuration `projects\<id>.json`. The main program,
installers, manifests, checksums, and logs in the output directory are kept.

## The window

- **Frameless, hand-drawn title bar**: minimise / maximise / close are drawn by the frontend; the bar
  drags the window and double-click toggles maximise. Eight transparent hit zones take over edge resizing.
- **Window materials**: on Windows 11 with Mica Alt enabled, the title bar, sidebar and status bar go
  translucent while the content area stays opaque. "Reduce transparency" falls back to solid colours.
- **Window size and maximised state are remembered, position is not** — the window always opens centred.
- The window is created with `visible: false`; the frontend shows it after the first frame, with a 1.5 s
  Rust fallback.

## One Fluent theme

The UI is React + Fluent UI React v9 + Griffel. There is one Fluent design and no second skin.

| Item | Value |
| --- | --- |
| Accent | Windows 11 blue `#005FB8` |
| Type | Segoe UI Variable Text / Display; Cascadia Mono for paths, logs and code |
| Body | 14 px / 20 px; 30 px tree rows; 32 px controls |
| Canvas | Light grey canvas with white content cards; secondary sections sit directly on the canvas |
| Radius | 4 px controls, 8 px panels |

Light/dark has three modes: `auto (follow system) → dark → light → auto`, stored in
`localStorage["sealpack:theme"]`. Auto is the default and follows the Windows app mode; a manual choice
is not overridden by the system.
