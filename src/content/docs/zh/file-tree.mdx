## 点击语义

| 区域 | 点击行为 |
| --- | --- |
| 整行（名称 / 图标 / 大小 / 状态） | 切换选中；锁定项只聚焦，不改变勾选 |
| 展开箭头 | 只展开 / 折叠，**不改任何勾选** |
| 勾选框 | 只勾选 / 取消（目录含整棵子树），**不折叠** |

目录行被点击时按三态聚合切换整棵子树；要展开目录请点箭头。这样「想展开却勾了一片」不会再发生。

<Callout tone="note" label="键盘">

文件树是 roving tabindex：整棵树只有一个焦点位，用 <Kbd>↑</Kbd> <Kbd>↓</Kbd> 移动、
<Kbd>→</Kbd> <Kbd>←</Kbd> 展开 / 折叠或进入 / 返回上层、<Kbd>空格</Kbd> 或 <Kbd>Enter</Kbd> 切换勾选。
<Kbd>Ctrl</Kbd> + <Kbd>A</Kbd> 全选当前可见文件。

</Callout>

## 三条找文件的路径

1. **知道大概在哪** → 直接展开目录看。树默认不过滤，结构完整。
2. **知道类型** → 点类型 chip 收敛，例如只看 `.dll`。
3. **知道名字** → 搜索框。命中高亮、祖先自动展开，搜索前后会记住手工折叠的状态。

打包页的「全部打包 / 全部排除」会遍历整棵树，覆盖折叠目录与筛选之外的文件；自动排除、规则命中和主程序保持不变。
所以「全部排除」后计数通常不是 0 —— 主程序始终锁定为打包。

## 视图变了 ≠ 勾选变了

- **勾选变了** 要写回工程、触发防抖保存；
- **视图变了**（折叠、搜索、类型筛选）只改变「看得见几个」，不落盘。

底栏的「当前显示 N 个」必须跟着视图刷新。扫描目录与刷新排除项各自有单调递增的 epoch，
切换工程时旧请求回来会被丢弃；两个计数器必须分开。

<Callout tone="pitfall" label="目录里删了文件">

在资源管理器里删掉文件后，树不会自动知道。右键工程行选「重新加载工程」，
它会重读工程 JSON 并重新扫描主程序目录。

</Callout>
