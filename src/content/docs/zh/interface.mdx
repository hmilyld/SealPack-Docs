## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| <Kbd>Ctrl</Kbd> + <Kbd>,</Kbd> | 打开设置 |
| <Kbd>Ctrl</Kbd> + <Kbd>W</Kbd> | 关闭窗口 |
| <Kbd>Alt</Kbd> + <Kbd>←</Kbd> / <Kbd>→</Kbd> | 向导上一步 / 下一步 |
| <Kbd>Esc</Kbd> | 关闭右键菜单 / 对话框 |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd> <Kbd>Home</Kbd> <Kbd>End</Kbd> | 文件树与菜单中移动焦点 |
| <Kbd>→</Kbd> <Kbd>←</Kbd> | 文件树中展开 / 折叠、进入 / 返回上层 |
| <Kbd>空格</Kbd> / <Kbd>Enter</Kbd> | 切换文件树勾选状态 |
| <Kbd>Ctrl</Kbd> + <Kbd>A</Kbd> | 全选当前可见文件 |

对话框内 <Kbd>Tab</Kbd> 在面板内部循环，<Kbd>Enter</Kbd> 触发主操作；主操作在右侧，取消在左侧（Fluent 约定）。
设置对话框打开时焦点先落在对话框容器上，不会一进来就给第一个 tab 画焦点框。

<Callout tone="pitfall" label="不要吞掉 Esc">

全局快捷键表在 `window` 的**捕获**阶段处理，只 `preventDefault`、**不** `stopPropagation`。
浮层（对话框、右键菜单）需要自己处理 <Kbd>Esc</Kbd> —— 全局表把它吞掉的话，对话框就关不上了。

</Callout>

## 右键菜单

| 位置 | 菜单项 |
| --- | --- |
| 工程行 | 打开主程序目录 / 打开输出目录 / 重新加载工程 / 复制工程名 / 重命名… / 删除工程… |
| 文件树 | 复制路径 / 在资源管理器中显示 |
| 运行日志 | 复制全部输出 / 保存日志 / 清空日志 |
| 输入框与脚本区 | 系统原生编辑菜单（剪切 / 复制 / 粘贴 / 拼写检查） |

「重新加载工程」会先保存当前未保存的修改，再从磁盘重读工程 JSON，并重新扫描主程序目录；
在资源管理器里删了文件后用它刷新列表。

「重命名…」会打开弹窗，自动预填主程序版本信息里的 `ProductName`（拿不到就用文件名）。
工程名会用于安装包名、默认安装目录和输出文件名；主程序与输出目录里的旧文件不会被改名。

「删除工程…」只删除工程配置 `projects\<id>.json`，主程序、输出目录里的安装包、校验清单和日志都会保留。

## 窗口

- **无边框自绘标题栏**：最小化 / 最大化 / 关闭由前端绘制，标题栏可拖拽、双击最大化。
  无边框窗口在 Windows 上会失去系统边缘缩放，因此另用 **8 个透明热区**接管四边四角。
- **窗口材质**：Windows 11 上启用 Mica Alt 后标题栏 / 侧栏 / 状态栏半透明，内容区保持实色。
  系统开启「减弱透明度」时自动退回实色。
- **窗口尺寸与最大化状态会被记住，位置不会** —— 位置始终居中，避免上次把窗口拖到已拔掉的显示器上之后找不着。
- 窗口以 `visible: false` 创建，前端在首帧绘制完成后 `show()`，Rust 侧另有 1.5 秒兜底。

## 一套 Fluent 主题

界面使用 React + Fluent UI React v9 + Griffel，只有一套 Fluent 设计，不再有第二套皮肤。

| 项 | 取值 |
| --- | --- |
| 主色 | Windows 11 蓝 `#005FB8` |
| 字体 | Segoe UI Variable Text / Display；路径、日志与代码用 Cascadia Mono |
| 正文 | 14px / 20px；树行 30px；控件高度 32px |
| 画布 | 浅灰画布 + 白色内容卡；次级分区直接落在画布上 |
| 圆角 | 控件 4px、面板 8px |

明暗有三种模式：`自动（跟随系统） → 深色 → 浅色 → 自动`，存在 `localStorage["sealpack:theme"]`。
默认自动，尊重 Windows 的「应用模式」；手动指定后不再被系统覆盖。
