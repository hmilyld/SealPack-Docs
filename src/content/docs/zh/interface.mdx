## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| <Kbd>Ctrl</Kbd> + <Kbd>,</Kbd> | 打开设置 |
| <Kbd>Ctrl</Kbd> + <Kbd>W</Kbd> | 关闭窗口 |
| <Kbd>Alt</Kbd> + <Kbd>←</Kbd> / <Kbd>→</Kbd> | 向导上一步 / 下一步 |
| <Kbd>Esc</Kbd> | 关闭右键菜单 / 对话框 |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd> <Kbd>Home</Kbd> <Kbd>End</Kbd> | 文件树与菜单中移动焦点 |
| <Kbd>→</Kbd> <Kbd>←</Kbd> | 文件树中展开 / 折叠、进入 / 返回上层 |
| <Kbd>空格</Kbd> / <Kbd>Enter</Kbd> | 切换文件树勾选状态 |

对话框内 <Kbd>Tab</Kbd> 在面板内部循环，<Kbd>Enter</Kbd> 触发主操作；
<Kbd>Esc</Kbd> 与点击遮罩都会正常结束对话框，不会卡住调用方。

<Callout tone="pitfall" label="不要吞掉 Esc">

全局快捷键表在 `window` 的**捕获**阶段处理，只 `preventDefault`、**不** `stopPropagation`。
浮层（对话框、右键菜单）需要自己处理 <Kbd>Esc</Kbd> —— 全局表把它吞掉的话，对话框就关不上了。

</Callout>

## 右键菜单

桌面程序右键一定有菜单。SealPack 用自绘菜单替掉 WebView2 的原生菜单，外观跟随当前皮肤，
键盘语义完整（<Kbd>↑</Kbd> <Kbd>↓</Kbd> 循环、<Kbd>Home</Kbd> / <Kbd>End</Kbd> 跳首尾、
<Kbd>Enter</Kbd> 执行、<Kbd>Esc</Kbd> 关闭并归还焦点），贴边时自动收拢到视口内。

| 位置 | 菜单项 |
| --- | --- |
| 工程行 | 打开主程序目录 / 打开输出目录 / 删除工程 |
| 文件树 | 勾选当前结果 / 全选 / 全不选 / 清空已选与筛选 / 重新扫描目录 |
| 输入框与脚本区 | 剪切 / 复制 / 粘贴 / 全选 |
| 运行日志 | 复制全部输出 / 清空日志 |
| 主题按钮 | 窗口材质开关（Mica Alt） |

## 窗口

- **无边框自绘标题栏**：最小化 / 最大化 / 关闭由前端绘制，标题栏可拖拽移动、双击切换最大化。
  无边框窗口在 Windows 上会失去系统提供的边缘缩放，因此另用 **8 个透明热区**接管四边四角。
- **窗口材质**：Windows 11 上启用 Mica Alt 后标题栏 / 侧栏 / 状态栏半透明，内容区保持实色。
  三道闸门任一不通过就完全退回实色：`set_effects()` 失败（Windows 10）、用户手动关闭（右键主题按钮）、
  系统开启「减弱透明度」。主题按钮上会出现 `▾` 表示该菜单存在。
- **窗口尺寸与最大化状态会被记住，位置不会** —— 位置始终居中，避免上次把窗口拖到已拔掉的显示器上之后找不着。
- 窗口以 `visible: false` 创建，前端在「写皮肤 → 两帧 rAF → `show()`」之后才显示，所以启动不闪白底；
  Rust 侧另有一个 1.5 秒的兜底显示，前端脚本出错也不会让窗口永不出现。

## 两套设计，三种明暗

标题栏的切换器上点一下即可实时切换，两套设计**共用同一份 DOM**，差异 100% 由 CSS 表达。

| 设计 | 字体 | 主色 | 手动模式下的默认主题 |
| --- | --- | --- | --- |
| 瑞士技术网格 | Instrument Sans + JetBrains Mono | 暖白纸底 `#faf8f5` + 朱红 `#d8332a` | 浅色 |
| 终端 · 赛博安全工具 | Chakra Petch + IBM Plex Mono | 近黑底 `#05070a` + 荧光青 `#35d6e8` / 酸绿 `#a3e635` | 深色 |


<Figure src="/shots/25-terminal-wizard-tree.png" alt="终端皮肤下的向导与文件树" caption="终端皮肤 —— 与上面几张是同一份 DOM，差异全部来自 CSS" />

明暗有三种模式，点「主题」按钮循环：`自动（跟随系统） → 深色 → 浅色 → 自动`。

默认**自动** —— 本地程序应当尊重 Windows 的「应用模式」设置，而不是自说自话。
系统明暗取自 `prefers-color-scheme`（WebView2 会把它映射到 Windows 应用模式），
系统一变界面立刻跟着变，不需要重启。一旦手动指定就不再被系统覆盖；
此时**每套设计各记自己的明暗**，切回某套设计时恢复它上次用的主题。

<Callout tone="note" label="为什么不 fork DOM">

皮肤与主题挂在 `<html>` 的 `data-skin` / `data-theme` / `data-themeMode` 上，是根元素属性。
对话框与提示条虽然挂在 `<body>` 上，也会同时切换，不存在「部分元素还是旧皮肤」的中间态。
一旦为某套皮肤 fork DOM，两边的行为就会开始漂移 —— 而漂移只有用户能看见。

</Callout>
